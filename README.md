# Oraculum

Містичний щоденний оракул із передбаченням і побажанням. Оберіть картку, щоб отримати випадкове послання на день; дата відображається українською мовою.

## Можливості

- Дві незалежні картки: «Передбачення на день» і «Побажання на день».
- У початковому стані картки показують лише заголовок і кнопку; після натискання з’являються одна з 40 фраз-передбачень або 46 побажань та одна з чотирьох оригінальних SVG-ілюстрацій.
- Для тієї самої картки поспіль не повторюються ані фраза, ані ілюстрація.
- Поточна дата у форматі «день місяць».
- Адаптивний інтерфейс у містичній палітрі та іконки Lucide.
- Компоненти Material UI `Card` і `Button` із налаштованою темою проєкту.
- Маршрутизація React Router для головної сторінки та невідомих адрес.

## Технології

- React 19 і TypeScript
- Vite 8
- React Router
- Material UI (`@mui/material`) та Emotion (`@emotion/react`, `@emotion/styled`)
- Lucide React
- ESLint

## Виконання практичного завдання

У проєкті обрано **Material UI**. Бібліотеку та потрібні для неї Emotion-пакети додано до `dependencies`:

```sh
npm install @mui/material @emotion/react @emotion/styled
```

| Вимога завдання | Реалізація |
| --- | --- |
| Вибрати одну бібліотеку компонентів | Обрано Material UI; Tailwind CSS та Ant Design не підключалися. |
| Створити компоненти в `src/components` | Створено `Header.tsx` і повторно використовуваний `ReadingCard.tsx`. |
| Використовувати компоненти обраної бібліотеки | `ReadingCard` використовує MUI `Card` і `Button`; тема визначена в `src/theme.ts`. |
| Імпортувати компоненти в застосунок і передавати props | `App.tsx` імпортує компоненти та передає карткам заголовки, іконки, текст кнопок, дані послання й обробники натискання. |
| Забезпечити адаптивність і функціональність | Картки перебудовуються в один стовпець на вузьких екранах; кнопки відкривають випадкові послання та дозволяють отримати інші. |

Компоненти мають розширення `.tsx`, а не `.jsx`, оскільки проєкт уже використовує TypeScript. Окремої форми в інтерфейсі за задумом немає: взаємодія виконується кнопками карток, тому компонент `Form` для цього завдання не потрібен.

## Запуск локально

Встановіть залежності:

```sh
npm install
```

Запустіть сервер розробки:

```sh
npm run dev
```

Vite покаже локальну адресу в терміналі. Зміни у вихідних файлах відображаються під час розробки завдяки HMR.

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запустити сервер розробки |
| `npm run build` | Перевірити TypeScript і створити production-збірку в `dist/` |
| `npm run lint` | Запустити ESLint |
| `npm run preview` | Локально переглянути production-збірку |

Перед розгортанням виконайте `npm run build`. Для роботи клієнтської маршрутизації на статичному хостингу налаштуйте перенаправлення невідомих шляхів на `index.html`.

## Структура проєкту

- `src/App.tsx` — фрази, стан послань і маршрути.
- `src/components/Header.tsx` — шапка сторінки.
- `src/components/ReadingCard.tsx` — картка послання на базі MUI, налаштовується через props.
- `src/theme.ts` — тема Material UI.
- `src/App.css` і `src/index.css` — стилі сторінки.
- `src/main.tsx` — точка входу React, маршрутизатор і `ThemeProvider` Material UI.
- `index.html` — HTML-шаблон і метадані сторінки.
