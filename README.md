# Oraculum

Містичний щоденний оракул із передбаченням і побажанням. Оберіть картку, щоб отримати випадкове послання на день; дата відображається українською мовою.

## Можливості

- Дві незалежні картки: «Передбачення на день» і «Побажання на день».
- У початковому стані картки показують лише заголовок і кнопку; після натискання з’являються одна з 40 фраз-передбачень або 46 побажань та одна з чотирьох оригінальних SVG-ілюстрацій.
- Для тієї самої картки поспіль не повторюються ані фраза, ані ілюстрація.
- Поточна дата у форматі «день місяць».
- Адаптивний інтерфейс у містичній палітрі та іконки Lucide.
- Маршрутизація React Router для головної сторінки та невідомих адрес.

## Технології

- React 19 і TypeScript
- Vite 8
- React Router
- Lucide React
- ESLint

## Вимоги

- Node.js 20.19+ або 22.12+
- npm

## Запуск локально

Встановіть залежності:

```sh
npm install
```

Запустіть сервер розробки:

```sh
npm run dev
```

Vite покаже локальну адресу в терміналі. Зміни у вихідних файлах відображаються під час розробки завдяки HMR.

## Команди

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запустити сервер розробки |
| `npm run build` | Перевірити TypeScript і створити production-збірку в `dist/` |
| `npm run lint` | Запустити ESLint |
| `npm run preview` | Локально переглянути production-збірку |

Перед розгортанням виконайте `npm run build`. Для роботи клієнтської маршрутизації на статичному хостингу налаштуйте перенаправлення невідомих шляхів на `index.html`.

## Структура проєкту

- `src/App.tsx` — картки, фрази та маршрути.
- `src/App.css` і `src/index.css` — стилі сторінки.
- `src/main.tsx` — точка входу React і налаштування маршрутизатора.
- `index.html` — HTML-шаблон і метадані сторінки.
